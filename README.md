# FinFlow — управление вкладами и текущими счетами банка

Учебный программный комплекс по пояснительной записке «Управление вкладами и
текущими счетами банка». Система автоматизирует работу отделения банка по
обслуживанию клиентов, счетам и вкладам: регистрацию клиентов, открытие и
закрытие счетов, оформление договоров вкладов, кассовые и безналичные операции,
начисление и выплату процентов с удержанием налога, закрытие операционного дня
и отчётность руководителя о работе сотрудников.

Аналитические и надзорные контуры (риски, ликвидность, маржа, ПОД/ФТ, интеграции
с внешними системами) в систему **не входят** — они удалены из кода, интерфейсов,
начальных данных, тестов и документации.

## Роли пользователей

| Роль | Интерфейс | Возможности |
|------|-----------|-------------|
| Сотрудник банка | WPF | Поиск и регистрация клиентов, открытие текущих счетов и вкладов, карточка счёта, ограничения и овердрафт, операции по счёту и сторнирование, закрытие операционного дня |
| Администратор | WPF | Создание и блокировка учётных записей сотрудников, журнал аудита, отчёт о работе сотрудников |
| Руководитель | WPF | Отчёт о работе сотрудников за выбранный период: клиенты, счета, вклады, суммы, операции, закрытия дня |
| Клиент банка | Веб `/client/` | Вход по паспортным данным и дате рождения; свои вклады, сроки, начисления, условия досрочного возврата и опубликованные условия вкладов |

## Технологический стек

| Слой | Технология |
|------|-----------|
| Платформа | .NET 10 (C# 14) |
| Сервер приложений | ASP.NET Core 10 Web API, Swagger (Swashbuckle 10.3) |
| Доступ к данным | Entity Framework Core 10, SQL Server (LocalDB для разработки) |
| Рабочее место сотрудника | WPF (MVVM), .NET 10 Windows |
| Личный кабинет клиента | SPA без внешних зависимостей по адресу `/client/` |
| Тесты | xUnit v3 + Microsoft Testing Platform, контрольные примеры формул (1.1)–(1.10) |

## Структура решения

```
FinFlow.sln
├── src/
│   ├── FinFlow.Domain/          сущности, перечисления, расчётные классы, модельные данные
│   ├── FinFlow.Contracts/       DTO и запросы API (общие для сервера и клиентов)
│   ├── FinFlow.Application/     сервисы, абстракции, маппинг, бизнес-правила
│   ├── FinFlow.Infrastructure/  EF Core DbContext, Unit of Work, хеширование паролей,
│   │                            хранилища токенов, инициализация и заполнение БД
│   ├── FinFlow.Api/             REST API, аутентификация, Swagger, личный кабинет /client/
│   └── FinFlow.Desktop/         WPF-клиент рабочих мест сотрудника, администратора, руководителя
├── tests/FinFlow.Tests/         контрольные расчёты и свёртка отчёта
└── docs/                        архитектура, требования, расчёты, руководства, API
```

Зависимости направлены внутрь: `Api`/`Desktop` → `Infrastructure` → `Application`
→ `Domain`; `Contracts` используется сервером и клиентами. Домен не знает о EF Core
и ASP.NET Core.

## Реализованные функции

| Блок | Реализация |
|------|-----------|
| Клиенты | Регистрация физлиц, юрлиц и ИП, идентификация, поиск, изменение контактов — `ClientService` |
| Счета | Открытие и закрытие, прежний (13 знаков) и изменённый (17 знаков с 01.01.2027) номера, лимит овердрафта — `AccountService`, `AccountNumberGenerator` |
| Проценты по остатку | Доступный остаток D = max(0; B + L − H), L = 0 при аресте — `BalanceCalculator`, `BalanceService` |
| Ограничения | Аресты, бронирования, авторизационные блокировки — `HoldService` |
| Вклады | Продукты и версии условий, договор вклада, пролонгация, досрочный возврат — `ProductService`, `ContractService`, `EarlyReturnCalculator` |
| Операции | Касса, безналичные поступления и списания, частичное снятие, досрочный возврат; проверка остатка и исполнение в одной транзакции; сторнирование — `OperationService` |
| Проценты и налог | Ежедневное начисление (1.5), капитализация и выплата (1.6)–(1.7), подоходный налог (1.8) — `InterestService`, `TaxService`, `DayCloseService` |
| Закрытие дня | Начисление, выплаты, пролонгация и возврат вкладов; этапы сохраняются и повторный запуск продолжает обработку — `DayCloseService` |
| Отчётность | Отчёт по сотрудникам за период — `StaffReportService`, `StaffWorkCalculator` |
| Администрирование | Учётные записи, блокировка, журнал аудита — `AdminService`, `AuditService` |
| Личный кабинет | Вклады клиента, начисления, доход, оценка досрочного возврата, условия вкладов — `ClientPortalService` |

## Быстрый старт

```bash
dotnet restore FinFlow.sln
dotnet build FinFlow.sln -c Release
dotnet run --project src/FinFlow.Api -c Release      # http://localhost:5080
```

- Swagger: `http://localhost:5080/swagger`
- Личный кабинет клиента: `http://localhost:5080/client/` (корень `/` перенаправляет туда)

База создаётся и заполняется при старте (`EnsureCreated` + `DbSeeder`); строка
подключения — `ConnectionStrings:Default` в `appsettings.json` (по умолчанию LocalDB).

WPF-клиент:

```powershell
dotnet run --project src/FinFlow.Desktop -c Release
```

Адрес API задаётся переменной окружения `FINFLOW_API` (по умолчанию `http://localhost:5080`).
