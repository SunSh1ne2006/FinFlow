# Расчётные формулы и контрольные примеры

Все суммы округляются до копеек единым правилом `Money.Round` (банковское
округление до двух знаков). Формулы реализованы в `FinFlow.Domain/Calculators`
и покрыты тестами `tests/FinFlow.Tests/DomainCalculationsTests.cs`.

## 1. Остаток и доступные средства

### (1.1) Доступный остаток

```
D = max(0; B + L − H)
```

- `B` — балансовый остаток счёта (может быть отрицательным при овердрафте);
- `L` — лимит овердрафта; при действующем аресте `L = 0`;
- `H` — сумма действующих ограничений (аресты, бронирования, авторизации).

| B | L | H | Арест | D |
|---|---|---|-------|---|
| 12 000 | 5 000 | 3 000 | нет | **14 000** |
| −2 000 | 5 000 | 0 | нет | **3 000** |
| 3 000 | 5 000 | 4 000 | да | **0** |

### (1.2) Остаток после операций

```
B_t = B_0 + ΣC_j − ΣW_k
```

`B_0 = 10 000`, поступления 5 000 и 2 500, списание 1 000 → **16 500**.

### (1.3)–(1.4) Использование овердрафта

```
D_used = max(0; −B)
K_овд  = D_used / L × 100 %
```

## 2. Проценты

### (1.5) Простые проценты за период

```
I = Σ S_d × r_d / (100 × D_y)
```

`S_d` — база начисления дня (тело вклада или остаток текущего счёта),
`r_d` — ставка дня в процентах годовых, `D_y` — расчётное число дней в году
(365, 366 или фактическое).

Контрольный пример: 10 000 под 11,5 % за 31 день при `D_y = 365`:

```
I = 10 000 × 11,5 / (100 × 365) × 31 = 97,67 р.
```

Начисление по дням с неизменным остатком даёт тот же результат.

### (1.6) Капитализация

```
S_n = S_0 × (1 + r / (100 × m))^n
```

`m = 12` (ежемесячная капитализация), `n` — число месяцев.
10 000 под 11,5 % за 3 месяца → **10 290,26 р.**

### (1.7) Эффективная ставка

```
r_eff = ((1 + r / (100 × m))^m − 1) × 100
```

11,5 % при ежемесячной капитализации → **12,13 %** годовых.

## 3. Налог с процентов

### (1.8) Подоходный налог

```
N = max(0; I − I_дс) × t / 100
```

`I_дс` — проценты по ставке до востребования (0,1 %), `t` — ставка налога (13 %).

Контрольный пример: начислено 97,67, ставка до востребования 0 → база 97,67,
налог **12,70 р.**

Освобождение:
- вклад в BYN сроком не менее **365 дней**;
- вклад в иностранной валюте сроком не менее **730 дней**;
- проценты юридических лиц рассчитываются в ином порядке и в систему не входят.

## 4. Досрочный возврат

### (1.9) Проценты по договорной ставке

```
I_дог = S × r_дог / (100 × D_y) × d
```

`d` — фактическое число дней с даты открытия.

### (1.10) Перерасчёт и удержание излишка

```
I_дс  = S × r_дс / (100 × D_y) × d
U     = max(0; I_дог − I_дс)
P     = S + I_дс − U
```

Контрольный пример: 5 000 под 9 % через 120 дней, ставка до востребования 0,1 %:

| Показатель | Значение |
|------------|----------|
| `I_дог` | 147,95 р. |
| `I_дс` | 1,64 р. |
| выплата `P` (без ранее выплаченных процентов) | 5 001,64 р. |
| удержание `U` при выплаченных 147,95 | 146,31 р. |
| выплата `P` при удержании | 4 853,69 р. |

Выплата `P` перечисляется клиенту, остаток счёта вклада обнуляется, счёт и
договор закрываются. Безотзывный вклад возвращается досрочно только после
согласия банка; без согласия расчёт помечается как недопустимый.

## 5. Закрытие операционного дня

1. **Отклонение черновиков.** Операции в статусе «Черновик» отклоняются с
   причиной «Не проведена в течение операционного дня».
2. **Начисление.** По каждому действующему договору создаётся начисление за
   дату; уникальный индекс (договор, дата) исключает дубли.
3. **Выплата или капитализация.** В день выплаты (ежемесячно или в конце срока)
   проценты зачисляются на счёт с удержанием налога; при капитализации сумма
   увеличивает тело вклада.
4. **Пролонгация и возврат.** Вклад с наступившим сроком пролонгируется, если
   это разрешено условиями, иначе возвращается на счёт, счёт закрывается.
5. **Итоги.** Количество начислений, сумма процентов и удержанного налога
   сохраняются в операционном дне.

## 6. Показатели отчёта руководителя

| Показатель | Источник |
|------------|----------|
| Клиентов зарегистрировано | `Clients.CreatedBy`, `CreatedAt` в периоде |
| Счетов открыто | `Accounts.CreatedBy`, `CreatedAt` |
| Вкладов открыто | `Contracts` с продуктом вида «Вклад» |
| Сумма вкладов | сумма `Contracts.Principal` |
| Операций и оборот | `Operations.CreatedBy`, `CreatedAt`, сумма `Amount` |
| Закрытий дня | записи `AuditLog` с действием `DayClosed` |

Итоги по отделению рассчитывает `StaffWorkCalculator.Summarize` (суммы
округляются до копеек).
